# 刀剑 · 心流

> 本游戏是以心流和博弈为主要玩法的 2D 轻量化格斗游戏，用最简单的操作表现二人真剑决斗的瞬息万变。支持单人游戏和本地双人游戏。

## 一、基本信息

| 项 | 内容 |
|---|---|
| 作品名 | 刀剑 · 心流（Sword · Flow） |
| 版本 | 0.1.0 |
| 平台 | Windows 10 / 11，64 位 |
| 引擎 | Godot 4.7.2（Forward+ 渲染，Vulkan） |
| 语言 | 简体中文 / English（设置页可切换，即时生效） |
| 模式 | 单人阶梯（连续挑战 5 位对手）、本地双人（同一台电脑对战） |
| 时长 | 单局约 1 分钟，单人一轮 5 场 |
| 网络 | 无需联网，无内购 |

## 二、配置要求

下表按本作的实际规模（2D、Godot Forward+、60 Hz 固定帧、约 120 MB 单可执行文件）估算。

| | 最低配置 | 推荐配置 |
|---|---|---|
| 操作系统 | Windows 10 64 位（1903 及以上） | Windows 10 / 11 64 位 |
| 处理器 | 双核 2.0 GHz（x86_64） | 四核 2.5 GHz 及以上 |
| 内存 | 4 GB | 8 GB |
| 显卡 | 支持 Vulkan 1.0 的集成显卡（Intel HD 530 / GeForce GT 730 级），1 GB 显存 | 支持 Vulkan 1.1 的独立显卡（GeForce GTX 1050 / Radeon RX 560 级），2 GB 显存 |
| 存储空间 | 500 MB 可用空间 | 1 GB 可用空间（含存档与日志） |
| 显示 | 1280×720 | 1920×1080 |
| 输入 | 键盘，或 Xbox 布局手柄 | 键盘 + 手柄（双人对战建议两只手柄） |
| 其他 | — | 建议开启垂直同步；游戏逻辑固定 60 Hz |

## 三、为什么契合主题「心」

游戏机制围绕“心流”这一决定攻防窗口的资源，用内心博弈做出准确判断；除了机制上的心，由于美工原因，本游戏变成了“对抗心魔”的简短设定 —— “我要打倒内心的心魔！”“打完了。”

## 四、玩法与操作

玩家要准确判断对方的下一步行动并作出应对，也可以抢占先机令对手措手不及；注意动作的前摇和持续帧数，化解对手的攻击并击败对手。

### 操作

| 动作 | P1（键鼠） | P2（键鼠） | 手柄 |
|---|---|---|---|
| 斩 | J | I 或 小键盘 1 | A |
| 架 | K | O 或 小键盘 2 | B |
| 符卡 | L | P 或 小键盘 3 | Y |
| 暂停 | Esc | Esc | Start |
| 重开 | R | R | Back |

- 每名玩家可在选人界面各自选择「键盘」或「手柄」，双人同机对战互不干扰。
- 以上为默认键位，设置页可逐项改键、检测冲突并恢复默认。

## 五、亮点

简单且爽快的决斗。

## 六、AI 使用情况

本作允许范围内的 AI 使用集中在**代码工程**：游戏逻辑、测试、构建与工具脚本由 AI 辅助实现，玩法、数值与内容取舍由人决定并试玩复核；**美术、音乐、音效与文案 0% AI 生成**。

| 范围 | AI 参与 | 说明 |
|---|---|---|
| 游戏代码（GDScript / 场景 / 着色器） | 约 100% 由 AI 起草 | 人类确定玩法与数值、逐轮试玩复核并调整 |
| 自动化测试（GUT，311 项全通过） | 约 100% | 判定矩阵、心流、AI、输入、UI 与存档 |
| 构建与工具脚本（导出、截图、资源流水线） | 约 100% | 人类指定目标与验收标准 |
| 内部工程文档（AI 披露、设计稿、检查清单） | 约 100% | 内部文档，不随作品面向玩家 |
| 美术 / 音乐 / 音效 / 文案（含本 README 正文） | 0% | 人类创作或 CC0 授权素材；本 README 由团队撰写 |
| 应用图标 | 0% AI 生成 | 人类素材拼接（自有阴阳图 + 原底板），不属 AI 生成美术 |

- AI 产品：DeepSeek Harness（编码代理，模型 deepseek 4.1 flash）。
- 逐模块的用途、AI 率与人类复核记录见随附的 `ai-disclosure.md`（仓库内 `docs/gamejam/ai-disclosure.md`），可按需提供日志与仓库访问。
