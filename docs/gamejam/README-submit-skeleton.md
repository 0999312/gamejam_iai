## 2. 已核实事实（可直接引用，2026-11-06 构建）

| 项 | 值 | 来源 |
|---|---|---|
| 作品名（本地化） | zh_CN「刀剑 · 心流」/ en「Sword · Flow」 | `localization/zh_CN.json` `menu.title` |
| 版本 | 0.1.0 | `project.godot` `config/version` |
| 引擎 | Godot 4.7.2 stable（Forward+） | `project.godot` `config/features` |
| 平台 | Windows x64（`iai.exe`，单文件含 pck） | `export_presets.cfg` |
| 分辨率 | 1280×720，`canvas_items` 拉伸，可窗口化 | `project.godot` `[display]` |
| 语言 | 简体中文 / English（设置页切换，即时生效） | `I18NManager` + 165 键 × 2 |
| 模式 | 单人进阶（5 位对手）、本地双人对战 | `menu.mode_*` |
| 角色 | 3 名（开发代号 A / B / C） | `menu.char_*` |
| 存档 | `%APPDATA%/iai/meta_save.json`（JSON，含备份） | `scripts/core/meta_save.gd` |
| 构建产物 | `iai.exe` 119,893,104 B；`windows.zip` 48,302,523 B | `build/windows/` |

**操作**（默认值，设置页可改键；每个玩家可选键鼠或手柄）：

| 动作 | P1（键鼠） | P2（键鼠） | 手柄 |
|---|---|---|---|
| 斩 | J | I 或 小键盘 1 | A |
| 架 | K | O 或 小键盘 2 | B |
| 符卡 | L | P 或 小键盘 3 | Y |
| 暂停 | Esc | Esc | Start |
| 重开 | R | R | Back |

> 键位来源：`scripts/core/key_bindings.gd` `DEFAULT_KEYS` / `DEFAULT_JOY_BUTTONS`；玩家改键后以设置页为准。

**玩法事实**（供你组织叙述，不要照抄）：1v1 单线对峙；每刀分段判定，斩/架/虚招相互克制；心流值随正确读招积累，只放宽判定窗口与提示强度，不减伤、不改时间流速；单人模式逐级挑战 5 位对手，局间三选一「心得」强化；双人同机对战。
