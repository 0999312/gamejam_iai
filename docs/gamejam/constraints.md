## 3. 东方 Project 二次创作规约（必须遵守）

> 依据：https://touhou-project.news/guideline/ （2024-05-31 更新）。东方 Project 著作权归**上海爱丽丝幻乐团及 ZUN**所有。

**必须做**

- 作品中**明确声明**「本作是东方 Project 的二次创作」（游戏内 + 提交 README）。
- 遵守规约与常识范围内的同人活动边界。

**禁止做**

1. 损害东方 Project 形象的内容。
2. 侵害他人权利或可能侵害他人权利的内容（**含未经许可使用他人的二次创作素材/同人图/同人曲**）。
3. 让人误以为是东方 Project **官方**内容的内容（不得使用官方 LOGO、不得声称官方授权）。
4. **使用或公开原作游戏素材**（贴图、立绘、BGM、音效、文本等）；**只有截图与游玩视频例外**。
5. 公开原作游戏的结局。
6. 借原作内容或二次创作物传播个人思想/主张。
7. 未经二次创作者许可，再次利用其二次创作物。
8. 过度性表现、中伤特定个人/团体/人种等社会通念上明显不当的行为。
9. 未经 ZUN 本人许可，加工或公开其照片。

**流通与盈利**

- 本作**免费参与、不售卖**，符合规约；若日后上架需注意：浏览器/手机应用**仅限免费**（可含广告、可做去广告内购）；禁止众筹（未获个别许可）；企业以营利为目的需个别咨询；纠纷自负责任。

**落到本工程的判断**

- 允许：原创角色/原创世界观沿用东方设定、二创剧情与玩法、自制美术与音乐（**人类制作**）、对原作角色的再演绎。
- 禁止：从原作游戏提取的任何素材、网络上来源不明的东方同人素材、官方 LOGO/官方包装视觉。

## 4. 团队与协作

- 建议 **3–5 人**；常见分工 1 程序 + 1 美术 + 1 策划/关卡（参与指南:60）。
- **开始前就确认每个人的具体职责与可用时间**，避免中途有人退出导致项目瘫痪（参与指南:60）。
- 对成员职责无约束，一人可兼任多岗，配置由团队按需调整（参与指南:66）。
- 工具与版本管理不作约束，团队自定（参与指南:68）。
- 署名方式由团队自由决定（参与指南:62）。
- 流程问题可随时向主办方提出（参与指南:37）。

## 5. 提交要求与作品质量

- 提交：按主办方指定方法提交（参与指南:39-40）。
- 允许半成品/原型，但建议尽量提高完成度（参与指南:15）。
- **测试**：在不同设备/环境下运行，确认**没有崩溃和明显操作障碍**（参与指南:91）。
- **游戏介绍**：提交前写好 README，说明「为什么契合主题、玩法与操作、亮点」（参与指南:93）——注意：该 README 属**文案**，必须由人类撰写（见 §6）。
- **封面**：漂亮封面很重要（参与指南:93）——同样属美术资产，必须人类制作。
- 提交后通道关闭即封版，无补交机会。

## 6. AI 使用规范（摘要）

原文立场：支持用 AI 提升效率，但「**AI 只是一款工具，不能代替人类做所有的决策**」（参与指南:97）。

| 允许 | 禁止 |
|------|------|
| 用 AI 辅助**编写游戏代码**（GDScript/C#/shader/工具脚本）以避免重复劳动 | 用 AI 生成**美术**（立绘、场景、图标、UI 视觉、像素图、封面） |
| 用 AI 辅助工程配置、重构、调试、测试用例、性能分析 | 用 AI 生成**音乐/音效/配音** |
| 用 AI 辅助**内部工程文档**（如本目录、代码注释、AI 披露日志） | 用 AI 生成**文案**：剧情、对白、道具/技能描述、UI 文字、作品 README、宣发文案、标题/命名创意 |
| AI 参与策划讨论、方案对比（**最终决策必须由人作出并负责**） | 把 AI 产出当作「人类创作」隐瞒披露 |

- **必须披露**：AI 产品名称、用途范围、**AI 率**等指标；可通过日志披露，可提供仓库权限供主办方审查（主办方承诺保护隐私）（参与指南:99）。
- 维护入口：`docs/gamejam/ai-disclosure.md`（**每次 AI 参与开发后即时追加**，不要攒到最后补）。
- 判定原则：**只要文本/图像/声音会随作品一起交付给玩家**，就按「艺术资产」对待，只能由人创作；纯内部工程产物不算艺术资产，但仍计入披露。

## 8. 落地到本工程的开发规则

以下条款把上述约束翻译成本工程内可执行的动作：

1. **代码可以 AI 写，文案/美术/音乐不可以**：AI 只产出 `.gd`/`.cs`/`.tscn` 结构、shader、工具脚本、测试；**不得**生成游戏内文本（对白、旁白、道具描述、UI 文案）、README 正文、宣发文案、任何图像或音频。
2. **占位策略**：需要文案或美术时，人类提供文本/图片，或用明确标注的 `PLACEHOLDER`（如 `[待人类撰写]`）并登记到 `submission-checklist.md`，不得用 AI「先写一版凑数」。
3. **二次创作声明**：在游戏标题画面「关于」页与提交 README 中写明「本作是东方 Project 二次创作，东方 Project 版权归上海爱丽丝幻乐团及 ZUN 所有」，并附规约链接。
4. **不引入原作素材**：不导入任何 TH 原作解包资源；引用角色设定只写文字描述，由人类美术自行创作。
5. **AI 披露即时维护**：见 `ai-disclosure.md`；每个功能模块完成后追加一行（日期、模块、AI 产品、用途、AI 率估算、人类复核人）。
6. **时间盒**：按 18 天剩余倒排——优先「能玩通的最小闭环」，再考虑完成度与打磨；11-04 前冻结功能，11-05~11-06 只做测试、构建与提交材料。
7. **可提交性优先**：任何阶段都要保证能导出可运行构建（Windows exe 或 web），避免截止前才发现导出失败。
8. **多设备测试**：至少在 1 台非开发机（或不同分辨率/窗口模式）上跑通，记录结果。
9. **版本控制**：初始化 Git 并按日提交，既是备份，也是「活动期内完成」的时间证据与 AI 披露审查依据。
10. **人类决策留痕**：关键创意/玩法取舍由人决定，可在 `docs/gamejam/decision-log.md`（需要时创建）记录决策与理由，便于说明 AI 未替代人类决策。
