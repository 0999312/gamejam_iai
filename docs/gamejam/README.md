1. **主题契合**：作品须围绕主办方公布的主题（可自由理解），**不接受 NSFW**、任何违反创作规约或公序良俗的内容（参与指南:34）。

3. **必须披露 AI 使用情况**：所用 AI 产品、AI 率等指标，可通过日志披露，可提供仓库权限供审查（参与指南:99）。
4. **遵守东方 Project 二次创作规约**：作品须明示为二次创作、不得使用/公开原作游戏素材（截图、游玩视频除外）、不得损害东方形象等（详见 constraints.md §3）。
5. **截止即封版**：2026-11-07 10:00 后不得再迭代、不得再提交。
6. **按指定方式提交**：必须使用主办方指定的提交通道与方法，否则视为未在截止前提交（参与指南:39）。

## 本期主题

**活动主题原文（主办方公布）**

> 「心」
>
> 「心」不限定于人类情感，也可以是意志、决心、意识、记忆、灵魂、自我，或一个存在与世界之间的联系。你可以探讨人工智能与意识，也可以完全不涉及技术；可以从现实中的思考出发，也可以联系东方 Project 中的角色与设定，例如古明地姐妹、秦心。
>
> 「心」既可以是玩家阅读的内容，也可以是玩家操作的对象、游戏机制的规则，甚至是游戏系统本身所呈现的性质。
>
> 我们期待不同创作者对「心」的理解，也期待这些理解最终以不同的游戏形式呈现。

**本项目方向（由人类创意决定；AI 只做工程实现，不代写文案）**

- **一句话**：剑术（居合道）与心流——东方 Project 各角色之间的**瞬息间剑术对决**。
- **玩法关键词**：拔刀/居合、读招、抢一瞬、一击决胜、心流蓄势。
- **主题契合（初步，待策划定稿）**：
  - 「心」＝**心流**：专注到极致的状态，可作为核心资源/状态量（玩的是「进入心流」）。
  - 「心」＝**决心/意志**：胜负在出手之前，机制上奖励「敢等、敢先手」的判断。
  - 「心」＝**读心**：可借用东方既有设定（古明地觉/古明地恋的读心、秦心的情感面具）做角色差异化，但不使用原作素材。
- **待人类决定（AI 不代写）**：具体规则与胜负判定、心流的量化方式、出场角色、全部台词与旁白、UI 文字。
